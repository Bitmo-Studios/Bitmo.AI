📖 How to Extract & Run in File Explorer

1. Extracting the Zip File

  1. Open your Downloads folder in Windows File Explorer.
  2. Right-click Bitmo.zip and select Extract All...
  3. Click the Extract button at the bottom of the window.

2. Running Bitmo.exe

  1. Double-click the newly unzipped folder to open it.
  2. Look for Bitmo.exe inside the folder.
  3. Double-click Bitmo.exe to start the program!
